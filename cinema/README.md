# Nome do projeto
Absolute Cinema
 

## Dupla

 

- Nome 1: Roger Antunes

- Nome 2: Davi Piske

 

## Problema escolhido
Fazer um cinema
 
Ele é um sistema de funcionamento de um cinema comum, com ingressos, sessões, filmes e clientes

 

## Classes principais

 

- Classe 1: Cliente

- Classe 2: Filme

- Classe 3: Ingresso

- Classe 4: Sessão

 

## Relações entre classes

 Ingresso se associa com Cliente, pois um Ingresso precisa conhecer o Cliente, mas o Cliente existe independentemente do Ingresso. O Ingresso se relaciona com a Sessão, porém, o Ingresso é dependente da Sessão. Agora a Sessão relaciona-se com o Filme, com tudo, a Sessão só existe com o Filme.
 
## Como executar

bash

javac *.java

java Main

## O que o Main demonstra
Clientes, Filmes, Sessões e Ingressos
